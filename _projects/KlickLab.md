Krafton Jungle에서의 마지막을 장식하는 프로젝트 '나만의 무기'. 이때 우리 E3I3라는 팀명을 가진 우리 팀이 만든 KlickLab에 대해서 소개하겠다.

KlickLab은 사용자의 행동 분석을 통해 시각화 시켜주는 서비스이다. 사용자의 클릭 하나하나 모두 수집하여서 어떻게 이동하는지, 어디서 유입하는지, 사용자의 위치는 어떻게 되는지 수집하여서 서비스 제공자에게 시각화시켜서 서비스 제공자가 수익을 극대화하거나, 서비스 품질을 높일 수 있도록 도움을 주는 서비스이다. 대표적으로는 Google Analytics같은 서비스가 있고, 우리는 이 서비스를 따라해 보는것이 가치있다고 판단했다.

GitHub repository링크는 우측 상단에 Project GitHub Link 눌러서 접속이 가능하다.

말로 하는것보다 포스터를 보여주겠다.
